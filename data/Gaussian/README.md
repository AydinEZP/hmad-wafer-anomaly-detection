# Required Gaussian Dataset README

## Role in this project

This is the required controlled synthetic dataset used for the Gaussian simulation protocol, especially Questions 9--11. It is generated by code; no external download is needed.

Generator:

```text
src/gaussian_required_data.py
```

Runner:

```text
experiments/run_gaussian_required.py
```

Generated arrays and metadata are written to:

```text
outputs/gaussian_required/data/
```

## Common conventions

- Sequence observations are scalar.
- Sequence length is 100 unless a supplementary condition explicitly changes only block structure.
- Normal observations are sampled from `N(0,1)`.
- Anomalous block observations are sampled from `N(4,1)`.
- Project labels are `0 = normal` and `1 = anomaly`.
- Anomaly starts are inclusive.
- Anomaly ends are exclusive.
- Normal sequences use `-1` for unused start and end positions.
- Required Questions 9--11 use exactly one anomaly block per anomalous sequence.

## Seed policy

| Purpose | Seed |
|---|---:|
| Clean Gaussian training pool | 1405 |
| Question 9 dataset | 1406 |
| Sensitivity master pool | 1407 |
| Supplementary sweeps | 1408 |
| Exact-fraction subset shuffles | 1500--1503 |

Different deterministic seeds are intentionally used for independent training and test pools.

## Clean training pool

```text
Number of sequences: 200
Sequence length:      100
Class:                normal only
Distribution:         N(0,1)
```

Serialized files:

```text
outputs/gaussian_required/data/gaussian_train_sequences.npy
outputs/gaussian_required/data/gaussian_train_metadata.json
```

Both OC-SVM and HMAD reuse this same clean training pool.

## Question 9 dataset

```text
Normal sequences:       200
Anomalous sequences:     50
Sequence length:         100
Blocks per anomaly:        1
Anomaly block length:     20
Anomaly distribution:   N(4,1)
Shuffle:                disabled, so normal and anomaly groups remain grouped
```

Question 9 assigns hard states with:

```text
state 1 if x < 2
state 2 if x >= 2
```

It produces a `250 x 6` joint-feature matrix.

## Question 10 training

Question 10 fits the simplified HMAD model to the 200 clean normal sequences using:

```text
K = 2 hidden states
Gaussian emissions
initial self-transition = 0.90
maximum iterations = 10
convergence threshold = 0.01
OC-SVM nu = 0.10
gamma = scale
```

Because the training data contain one nominal Gaussian regime, complete one-state collapse is an accepted possible result. An unused state must not be interpreted as a learned anomaly class.

## Question 11 exact contamination sets

A shared sensitivity master pool is generated once and reused. Exact 1,000-sequence subsets are formed as follows:

| Target anomaly fraction | Normal | Anomaly | Total |
|---:|---:|---:|---:|
| 0.01 | 990 | 10 | 1,000 |
| 0.05 | 950 | 50 | 1,000 |
| 0.10 | 900 | 100 | 1,000 |
| 0.20 | 800 | 200 | 1,000 |

Each anomalous sequence contains one 20-step block. The same subset is used by HMAD, the all-one-state ablation, and all OC-SVM representations.

The 1,000-sequence size allows the requested anomaly fractions to be represented exactly.

## OC-SVM representations in the Gaussian experiment

- `flattened`: all 100 values;
- `global_summary`: five global statistics;
- `window_summary`: five windows with five statistics each.

The pre-specified primary Gaussian baseline is `global_summary`, because its features are invariant to the random position of the anomaly block. All three representations are still reported.

## Supplementary block-length sweep

```text
Anomaly fractions: 0.10
Normal sequences:  900
Anomalous sequences: 100
Blocks per anomaly: 1
Block lengths: 5, 10, 20, 30, 40
```

Only the block length changes across these conditions.

## Supplementary block-count sweep

```text
Anomaly fraction: 0.10
Normal sequences: 900
Anomalous sequences: 100
Block counts: 1, 2, 3
Length per block: 10
Minimum gap: 2
```

Increasing block count also increases total anomalous duration. This sweep therefore studies the implemented block-count conditions but does not perfectly isolate count from total anomaly exposure.

## Leakage controls

- Training and test sequences are generated independently.
- Training contains only normal sequences.
- The same generated test condition is used for every compared model.
- Feature scalers are fitted only on training features.
- Test labels are used only for evaluation.
- The zero score threshold is fixed; it is not optimized on test labels.
