# Archived Result Tables

These CSV files are selected machine-readable outputs from the archived project run:

- `wafer_hmad_metrics.csv`: primary HMAD, ablation, and comparison metrics on Wafer.
- `wafer_ocsvm_metrics.csv`: Wafer OC-SVM representation and `nu` sweep.
- `gaussian_metrics_rtest_0p10.csv`: required Gaussian comparison at anomaly fraction 0.10.
- `gaussian_sensitivity_metrics.csv`: Gaussian anomaly-fraction sensitivity.
- `gaussian_supplementary_sweeps.csv`: block-length and block-count sweeps.

Raw predictions, generated arrays, duplicate figure formats, and files containing machine-specific paths are not included. Regenerate the complete output tree with the commands in [`REPRODUCING_RESULTS.md`](../REPRODUCING_RESULTS.md).
